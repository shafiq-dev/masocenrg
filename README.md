# MASCO Energy

Corporate homepage explorations for MASCO Energy — five white-mode design directions built with Next.js.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The app redirects to `/main`, a gallery of all five homepage variants.

## Routes

- `/main` — direction picker
- `/home/classic`, `/home/minimal`, `/home/services`, `/home/split`, `/home/editorial` — homepage variants
